## Root cause
The deployer validates the Expo mobile config before build (template `expo_mongo_base_image_eas`). The value in `frontend/app.json` at **`expo.android.package`** is `app.emergent.trainer-finder-9f806c77e`. Its third segment (`trainer-finder-9f806c77e`) contains **hyphens**, which are illegal in Android package names — Android allows only letters, digits and underscores per dot-delimited segment. This is a hard, non-retryable validation error, so re-running the pipeline unchanged will fail identically. It is a config error, not an infra blip.

Note the bundle-ID value itself came from the recent bundle-ID change to `app.emergent.trainer-finder-9f806c77e`. That string is **valid as an iOS bundle identifier** (iOS permits hyphens) but **invalid as an Android package name** — the two fields have different rules and must not be assumed identical.
